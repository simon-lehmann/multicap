multicap - record many Windows application windows at once

  multicap check                     can this machine capture at all (exit 3 if not)
  multicap windows                   capturable windows: handle, pid, title, size
  multicap record --json '{...}' --seconds 12
  multicap record --config take.json --seconds 12
  multicap hook --pid N --out F.mp4 --seconds S
  multicap hook --pid N,M,... --dir D --seconds S
                                     record from injected graphics hooks: works
                                     with no display output at all. Several pids
                                     record at once, one file each, one thread each.
                                     Each game's own sound is recorded beside its
                                     picture as .wav (--no-audio to skip), with the
                                     offset between them computed in the report
  multicap serve [--port 7788]       take orders as newline-delimited JSON
